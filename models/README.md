# 3D-моделі для інтерактивного тренажера «Будова комп'ютера»

Покладіть у цю папку (`models/`) два файли у форматі `.glb`:

1. `gaming_pc.glb` — 3D-модель системного блока ПК (кнопка **«🖥 Системний блок»**).
2. `rog_strix_motherboard.glb` — 3D-модель материнської плати (кнопка **«🔌 Материнська плата ROG»**).

> **Примітка:** Навіть якщо файли `.glb` ще не додані у папку `models/`, тренажер у `index.html` автоматично відображає інтерактивний 3D-стенд із пульсуючими мітками (Hotspots 1–6) та дозволяє підвантажити будь-який `.glb` файл із комп'ютера кнопкою **«📂 Свій .glb»**.
