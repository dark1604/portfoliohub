# Тема 2. Програмне забезпечення

> **Сторінки підручника:** с. 38–46

---

## 💻 Операційні системи (ОС)

**Операційна система** — це головна програма, яка керує всіма ресурсами пристрою та забезпечує взаємодію між користувачем, програмами й апаратним забезпеченням.

| Тип пристрою | Популярні операційні системи |
| :--- | :--- |
| **Персональні комп’ютери (ПК)** | Windows 11, macOS, Linux, UNIX, ChromeOS, Ubuntu |
| **Смартфони та планшети** | Android, iOS, Tizen, Ubuntu Touch |
| **Смартгодинники** | Wear OS, watchOS, Tizen |
| **SmartTV (розумні телевізори)** | Android TV, tvOS, webOS, Tizen |

---

## 🔌 Драйвери

**Драйвер** (від англ. *driver* — «водій», «керівник») — спеціальна програма, яка «пояснює» операційній системі, як працювати з конкретним пристроєм (принтером, відеокартою, веб-камерою, мишею).

- У Windows стан драйверів можна перевірити у **Диспетчері пристроїв** (натисни `Win + X` → *Диспетчер пристроїв*).
- Якщо біля пристрою стоїть **жовтий знак оклику `!`** — драйвер відсутній або працює некоректно.

## 🧩 Види програмного забезпечення (ПЗ)

Усе програмне забезпечення поділяють на **3 великі групи**:

### 1. Системне ПЗ
Забезпечує роботу самого комп’ютера та його обслуговування:
- **Операційні системи**;
- **Драйвери**;
- **Утиліти** (програми для перевірки й оптимізації дисків, очищення системи);
- **Антивіруси** (наприклад, *Windows Defender*, український *Zillya!*);
- **Архіватори** (для стиснення файлів).

### 2. Прикладне ПЗ
Програми для вирішення конкретних завдань користувача:
- текстові, табличні, графічні, відео- та аудіоредактори;
- браузери та месенджери;
- навчальні програми, симулятори (*PhET*, *Matific*), програми для відеозв’язку;
- комп’ютерні ігри.

> 🇺🇦 **Знай наших:** Серед відомих українських розробників програм та ігор — студії **GSC Game World**, **Frag Lab**, а також проєкт **Universe** (Ярослав Морозов).

### 3. Інструментальне ПЗ
Програми, призначені для створення інших програм (середовища програмування), наприклад **Scratch**.

## 🌐 Вебсервіси та безпечне завантаження програм

- **Вебсервіси** — це програми, які працюють безпосередньо у вікні браузера без встановлення на комп’ютер (наприклад, Google Документи, Canva, онлайн-перекладачі).
- **Безпечні джерела завантаження ПЗ:**
  - **офіційний сайт** розробника;
  - офіційні магазини застосунків: **Google Play**, **App Store**, **Microsoft Store**.

## 📜 Ліцензії на програмне забезпечення

Перед встановленням програми користувач приймає **ліцензійну угоду** — юридичний документ, що визначає правила використання ПЗ та захищає **авторське право** розробника.

### Основні види ліцензій:
1. **Власницьке (пропрієтарне) ПЗ:**
   - **Commercial** — платна програма (купується одноразово);
   - **Subscription** — програма за підпискою (щомісячна або щорічна оплата);
   - **Trial** — безкоштовна ознайомча версія з обмеженим часом роботи.
2. **Вільне та безкоштовне ПЗ (FLOSS):**
   - **FreeWare** — повністю безкоштовна програма (але код закритий);
   - **Open-source** — програма з відкритим вихідним кодом, який можна вивчати та змінювати;
   - **DonationWare** — безкоштовна, але з можливістю добровільно підтримати автора;
   - **Adware** — безкоштовна програма, яка показує рекламу.
