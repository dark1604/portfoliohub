# Тема 4. Діаграми та графіки (с. 27–30)

## 1. Рисунки SmartArt
**SmartArt** — готові наочні схеми, що ілюструють структуру, списки, послідовність кроків, цикли чи ієрархію (напр. *Ієрархія* для структури школи, *Цикл* для кругообігу води в природі).
- **Як додати:** *Вставлення → Ілюстрації → SmartArt* → обери категорію (напр. *Список → Вертикальний список*) → **ОК** → впиши текст у блоки.
- **Редагування** (вкладки *Конструктор* і *Формат*): **Додати фігуру**, перемістити **Угору / Униз**, змінити **Макети**, **Змінити кольори** та **Стилі SmartArt**.
- **Порада:** схема SmartArt має бути простою і зрозумілою — не перевантажуй її зайвими кольорами й ефектами.

## 2. Числові діаграми
**Діаграма** — це графічне представлення числових даних (таблиця перетворюється на наочний графік).

### 4 найпоширеніші види діаграм:
- **Стовпчаста** — для порівняння величин і відмінностей даних.
- **Лінійчата** (лінійна/графік) — для відображення динаміки змін у часі або порівняння кількох рядків.
- **Секторна** (кругова) — показує частки одного цілого та їхнє співвідношення.
- **Гістограма** (горизонтальні смуги) — коли горизонтальне розташування наочніше.

### Як додати й редагувати діаграму:
1. *Вставлення → Ілюстрації → Діаграма* → обери вид → **ОК**.
2. Відкриється таблиця **Microsoft Excel** — введи свої назви й числа і закрий вікно таблиці.
3. Щоб змінити цифри пізніше: права кнопка миші по діаграмі → **Редагувати дані**.
4. Щоб налаштувати шкалу осі (напр. *Мінімум*, *Максимум*, *Основні одиниці*): двічі клацни на числову вісь → панель **Формат осі → Параметри осі**.
