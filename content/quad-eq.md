# Квадратні рівняння та теорема Вієта

**Квадратним рівнянням** називається рівняння вигляду:

$$ax^2 + bx + c = 0$$

де $x$ — змінна, $a, b, c$ — деякі дійсні числа (коефіцієнти), причому старший коефіцієнт **$a \neq 0$**.

> **Важливо:** Якщо $a = 1$, то таке квадратне рівняння називають **зведеним** і записують у вигляді $x^2 + px + q = 0$.

## 1. Неповні квадратні рівняння

Якщо хоча б один із коефіцієнтів $b$ або $c$ дорівнює нулю, рівняння називається *неповним*:

| Тип рівняння | Умова | Метод розв'язування | Корені |
| :--- | :--- | :--- | :--- |
| $ax^2 = 0$ | $b = 0, c = 0$ | Ділення на $a$ | $x = 0$ (один корінь кратності 2) |
| $ax^2 + bx = 0$ | $c = 0$ | Винесення $x$ за дужки: $x(ax + b) = 0$ | $x_1 = 0, \quad x_2 = -\frac{b}{a}$ |
| $ax^2 + c = 0$ | $b = 0$ | Перенесення: $x^2 = -\frac{c}{a}$ | При $-\frac{c}{a} > 0$: $x_{1,2} = \pm\sqrt{-\frac{c}{a}}$ |

## 2. Формула дискримінанта

Для розв'язування повного квадратного рівняння $ax^2 + bx + c = 0$ обчислюють **дискримінант** за формулою:

$$D = b^2 - 4ac$$

Знак дискримінанта визначає кількість дійсних коренів рівняння:

1. **Якщо $D > 0$** — рівняння має **два різні дійсні корені**:
   $$x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}$$
2. **Якщо $D = 0$** — рівняння має **один корінь** (два рівні корені):
   $$x = -\frac{b}{2a}$$
3. **Якщо $D < 0$** — на множині дійсних чисел $\mathbb{R}$ **коренів немає** ($x \in \varnothing$).

## 3. Теорема Вієта

Нехай $x_1$ та $x_2$ — корені зведеного квадратного рівняння $x^2 + px + q = 0$. Тоді виконуються рівності:

$$\begin{cases} x_1 + x_2 = -p \\ x_1 \cdot x_2 = q \end{cases}$$

Для загального квадратного рівняння $ax^2 + bx + c = 0$:

$$x_1 + x_2 = -\frac{b}{a}, \qquad x_1 \cdot x_2 = \frac{c}{a}$$

### Приклад усного підбору коренів
Розв'яжемо рівняння $x^2 - 7x + 12 = 0$.
- Сума коренів: $x_1 + x_2 = 7$
- Добуток коренів: $x_1 \cdot x_2 = 12$
- Числа, що задовольняють обидві умови: **$x_1 = 3$** та **$x_2 = 4$**.

## 4. Автоматизація розв'язання на Python

Напишемо чисту функцію на Python для знаходження коренів квадратного рівняння з повною перевіркою граничних випадків:

```python
import math

def solve_quadratic(a: float, b: float, c: float) -> tuple:
    """Обчислює дійсні корені рівняння ax^2 + bx + c = 0."""
    if a == 0:
        raise ValueError("Коефіцієнт 'a' не може дорівнювати 0.")

    discriminant = b**2 - 4 * a * c
    print(f"Дискримінант D = {discriminant}")

    if discriminant > 0:
        sqrt_d = math.sqrt(discriminant)
        x1 = (-b - sqrt_d) / (2 * a)
        x2 = (-b + sqrt_d) / (2 * a)
        return (round(x1, 4), round(x2, 4))
    elif discriminant == 0:
        x = -b / (2 * a)
        return (round(x, 4),)
    else:
        return ()

# Тестування на рівнянні x^2 - 7x + 12 = 0
roots = solve_quadratic(1, -7, 12)
print("Знайдені корені:", roots)  # (3.0, 4.0)
```
