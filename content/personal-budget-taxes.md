# Особистий бюджет (50/30/20), податки ФОП та фінансова безпека

Фінансова незалежність починається не з розміру доходу, а з уміння керувати грошовими потоками (Cash Flow) та формувати резерви.

## 1. Правило бюджетування 50 / 30 / 20

Класична модель розподілу чистого місячного доходу $I_{\text{net}}$ після сплати податків:

$$I_{\text{net}} = 0.50 \cdot I_{\text{net}} + 0.30 \cdot I_{\text{net}} + 0.20 \cdot I_{\text{net}}$$

| Категорія | Частка | Що входить до категорії |
| :--- | :--- | :--- |
| **Базові потреби (Needs)** | $50\%$ | Житло, комунальні послуги, базові продукти, транспорт, здоров'я |
| **Бажання та дозвілля (Wants)** | $30\%$ | Хобі, гаджети, кафе, подорожі, підписки на сервіси |
| **Заощадження та інвестиції (Savings)** | $20\%$ | Резервний фонд, депозити, облігації, самоосвіта |

> **Фінансова подушка безпеки (Emergency Fund):** Це ліквідний резерв у розмірі від $3$ до $6$ місячних обов'язкових витрат:
> $$F_{\text{reserve}} = k \cdot E_{\text{monthly}}, \qquad k \in [3; 6]$$

## 2. Основи оподаткування ІТ-спеціалістів та фрілансерів (ФОП)

Більшість розробників, дизайнерів та фрілансерів в Україні працюють як **Фізичні особи-підприємці (ФОП) 3-ї групи** на спрощеній системі оподаткування.

Розрахунок чистого доходу при ставці єдиного податку $5\%$, військовому зборі з обороту та фіксованому ЄСВ:

```python
def calculate_fop_net_income(
    gross_income_uah: float,
    single_tax_rate: float = 0.05,
    military_levy_rate: float = 0.01,
    esv_monthly: float = 1760.0
) -> dict:
    """Розрахунок податкового навантаження ФОП 3-ї групи за місяць."""
    single_tax = gross_income_uah * single_tax_rate
    military_levy = gross_income_uah * military_levy_rate
    total_taxes = single_tax + military_levy + esv_monthly
    net_income = gross_income_uah - total_taxes

    return {
        "gross": round(gross_income_uah, 2),
        "taxes": round(total_taxes, 2),
        "net": round(net_income, 2),
        "effective_tax_pct": round((total_taxes / gross_income_uah) * 100, 2)
    }

print(calculate_fop_net_income(80000))
# {'gross': 80000, 'taxes': 6560.0, 'net': 73440.0, 'effective_tax_pct': 8.2}
```
