# Подільність натуральних чисел: прості числа, НСД та НСК

Теорія подільності допомагає швидко скорочувати дроби, розв'язувати текстові задачі на рух по колу та будувати криптографічні алгоритми.

## 1. Основні ознаки подільності

- **На 2:** Остання цифра числа парна ($0, 2, 4, 6, 8$).
- **На 5:** Остання цифра числа $0$ або $5$.
- **На 10:** Остання цифра числа $0$.
- **На 3:** Сума всіх цифр числа ділиться на $3$.
- **На 9:** Сума всіх цифр числа ділиться на $9$.

### Приклад
Перевіримо число $N = 4\,752$:
- Закінчується на $2$ $\implies$ ділиться на $2$.
- Сума цифр: $4 + 7 + 5 + 2 = 18$. Оскільки $18$ ділиться і на $3$, і на $9$, то і число $4\,752$ ділиться на $3$ та на $9$.

## 2. Прості та складені числа

- Натуральне число $p > 1$ називається **простим**, якщо воно має рівно два дільники: $1$ і саме себе ($2, 3, 5, 7, 11, 13, 17, 19, 23\dots$).
- Число $1$ не є ні простим, ні складеним.
- **Основна теорема арифметики:** Кожне натуральне число $n > 1$ можна єдиним способом (з точністю до порядку множників) подати у вигляді добутку простих чисел.

## 3. НСД та НСК та зв'язок між ними

Для будь-яких двох натуральних чисел $a$ і $b$ виконується фундаментальна тотожність:

$$\text{НСД}(a, b) \cdot \text{НСК}(a, b) = a \cdot b$$

Знайдемо $\text{НСД}(48, 36)$ і $\text{НСК}(48, 36)$:
1. Розкладемо на прості множники:
   $$48 = 2^4 \cdot 3^1, \qquad 36 = 2^2 \cdot 3^2$$
2. Для **НСД** беремо менші степені спільних множників: $\text{НСД}(48, 36) = 2^2 \cdot 3^1 = 12$.
3. Для **НСК** беремо більші степені всіх множників: $\text{НСК}(48, 36) = 2^4 \cdot 3^2 = 144$.

## 4. Алгоритм Евкліда на Python

```python
def gcd_euclid(a: int, b: int) -> int:
    """Знаходження НСД двох чисел за алгоритмом Евкліда."""
    while b != 0:
        a, b = b, a % b
    return a

def lcm(a: int, b: int) -> int:
    """Знаходження НСК через НСД."""
    return (a * b) // gcd_euclid(a, b)

print("НСД(48, 36) =", gcd_euclid(48, 36))  # 12
print("НСК(48, 36) =", lcm(48, 36))         # 144
```
