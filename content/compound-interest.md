# Складний відсоток, інфляція та математика депозитів

Розуміння часової вартості грошей — базовий інструмент фінансово грамотної людини. Розглянемо математичні моделі нарощення капіталу.

## 1. Простий vs Складний відсоток

Нехай $P$ (Principal) — початкова сума вкладу, $r$ — річна відсоткова ставка у десятковому вигляді (наприклад, $15\% = 0.15$), а $t$ — кількість років.

### Формула простого відсотка
Відсотки нараховуються лише на початкову суму $P$:

$$S_{\text{simple}} = P \cdot (1 + r \cdot t)$$

### Формула складного відсотка (Compound Interest)
Нараховані відсотки додаються до тіла вкладу (**капіталізуються**) і самі починають генерувати дохід:

$$S_{\text{compound}} = P \cdot \left(1 + \frac{r}{m}\right)^{m \cdot t}$$

де $m$ — кількість періодів капіталізації на рік ($m = 1$ — щорічна, $m = 4$ — щоквартальна, $m = 12$ — щомісячна).

> **Правило 72:** Щоб швидко оцінити, за скільки років капітал подвоїться при ставці $R\%$ річних, поділіть $72$ на $R$:
> $$T_{\times 2} \approx \frac{72}{R}$$
> Наприклад, під $12\%$ річних сума подвоїться приблизно за $72 / 12 = 6$ років.

## 2. Оподаткування депозитів та реальна дохідність

В Україні пасивний дохід за банківськими депозитами оподатковується (ПДФО + військовий збір). Якщо номінальна ставка банку становить $r_{\text{nom}}$, а сумарна ставка податку на прибуток з депозиту дорівнює $\tau$ (у частках одиниці), то **чиста ефективна ставка** становить:

$$r_{\text{net}} = r_{\text{nom}} \cdot (1 - \tau)$$

Для врахування рівня річної інфляції $i$ використовують **формулу Фішера** для реальної дохідності $r_{\text{real}}$:

$$r_{\text{real}} = \frac{1 + r_{\text{net}}}{1 + i} - 1$$

## 3. Симулятор накопичень на Python

Розрахуємо зростання капіталу з регулярним щомісячним поповненням:

```python
def simulate_savings(
    initial: float,
    monthly_add: float,
    annual_rate: float,
    years: int
) -> dict:
    """Симулятор депозиту зі щомісячною капіталізацією та поповненням."""
    months = years * 12
    monthly_rate = annual_rate / 12
    balance = initial
    total_invested = initial

    for _ in range(months):
        balance = balance * (1 + monthly_rate) + monthly_add
        total_invested += monthly_add

    profit = balance - total_invested
    return {
        "total_balance": round(balance, 2),
        "total_invested": round(total_invested, 2),
        "interest_earned": round(profit, 2)
    }

result = simulate_savings(initial=20000, monthly_add=2500, annual_rate=0.14, years=5)
print(result)
# {'total_balance': 256145.89, 'total_invested': 170000, 'interest_earned': 86145.89}
```
