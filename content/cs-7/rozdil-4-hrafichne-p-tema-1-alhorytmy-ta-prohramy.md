# Тема 1. Алгоритми та програми (с. 128–135)

## 1. Комп’ютерні програми, алгоритми та блок-схеми
> **Комп’ютерна програма** — список команд або вказівок, який зберігається у вигляді файлу на пристрої та виконується комп’ютером.

> **Мова програмування високого рівня** — мова програмування, що використовує слова з англійської мови, спеціальну граматику та синтаксис (*Python*, *Visual Basic*, *JavaScript*).

**Етапи створення програми:**
1. Визначити проблему та потрібні кроки.
2. Створити **алгоритм** (*Введення → Набір дій → Виведення*).
3. Накреслити **блок-схему**.
4. Написати код і запустити/протестувати програму.

> **Алгоритм** — покроковий список однозначних і простих інструкцій для розв’язання задачі (приклад у житті: рецепт страви або зав’язування шнурків).

> **Блок-схема** — графічне відображення алгоритму з послідовністю кроків, з’єднаних стрілками:
- **Овал (*Початок / Кінець*)** — початок і завершення алгоритму.
- **Паралелограм (*Введення / Виведення*)** — отримання та відображення даних.
- **Прямокутник (*Процес*)** — виконання дії або обчислення.
- **Ромб (*Умова / Рішення*)** — перевірка умови (*Так / Ні*, *Істинно / Хибно*).

## 3. Координати та кольори RGB у Python
- Базова одиниця екрана — **піксель**.
- У **pygame** точка **`(0, 0)`** розташована у **верхньому лівому куті** вікна! Координата `x` зростає праворуч, а координата `y` зростає **вниз** (на відміну від математики).
- **Колірна модель RGB** задає колір трьома цілими числами від **0 до 255** — інтенсивністю червоного (**R**), зеленого (**G**) і синього (**B**):
  - `Red = (255, 0, 0)`, `Lime = (0, 255, 0)`, `Blue = (0, 0, 255)`
  - `Yellow = (255, 255, 0)`, `Cyan = (0, 255, 255)`, `Magenta = (255, 0, 255)`
  - `White = (255, 255, 255)`, `Black = (0, 0, 0)`, `Teal = (0, 128, 128)`
- Колір у `pygame` можна передавати кортежем RGB або за назвою: `screen.fill("navy")`.
