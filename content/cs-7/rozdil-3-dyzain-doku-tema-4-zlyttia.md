# Тема 4. Злиття (с. 110–116)

## 1. Що таке злиття пошти?
> **Злиття пошти (Mail Merge)** — сервіс у Microsoft Word, який дає змогу автоматично створити персоналізовані документи (листи, запрошення, повідомлення електронної пошти, конверти, етикетки, каталоги) з одним основним текстом для багатьох різних одержувачів.

Запустити майстер можна на вкладці **Розсилки → Початок злиття → Розпочати злиття → Майстер злиття електронних повідомлень** (праворуч відкриється панель *Злиття* із 6 кроками).

---

## 2. Шість кроків злиття листів у Word
1. **Крок 1. Вибір типу документа:** оберіть **Листи** (або *Конверти*, *Етикетки*, *Повідомлення електронної пошти* для Outlook, *Каталог*) → *Далі. Відкриття документа*.
2. **Крок 2. Вибір документа:** оберіть **Поточний документ** (відкритий лист-заготовку), *Шаблон* або *Наявний документ* → *Далі. Вибір одержувачів*.
3. **Крок 3. Вибір одержувачів:**
   - **Створення списку → Створити** відкриває вікно *Новий список адрес*. Кнопкою **Настроїти стовпці** можна видалити зайві поля, залишивши, наприклад, лише *Ім’я*, *Прізвище*, *Адреса 1* (кожне поле видаляється окремо). Заповніть записи й збережіть список (`.mdb`).
   - Або оберіть **Наявний список** / **Використання списку** (наприклад, таблицю, заздалегідь створену в **Microsoft Excel**!) чи **Контакти Outlook**.
4. **Крок 4. Створення повідомлення:** виділіть шаблонне слово в тексті, натисніть **Інші елементи** (або *Блок адреси*, *Рядок привітання*) і вставте потрібні поля злиття (`«Ім_я»`, `«Прізвище»`, `«Адреса_1»`). Опція **Добір полів** зіставляє ваші стовпці зі стандартними назвами Word.
5. **Крок 5. Перегляд повідомлення:** перегляньте створені листи за допомогою стрілок `<<` та `>>`; за потреби виключіть певного одержувача кнопкою **Виключити одержувача**.
6. **Крок 6. Завершення злиття:** натисніть **Друк** або **Змінити окремі листи** → оберіть **Усі** (або *Поточний рядок* чи діапазон *З: ... до: ...*) → **ОК**. Word створить новий об’єднаний документ з окремим листом для кожного адресата.

---

## 3. Друк конвертів за допомогою злиття
1. На Кроці 1 оберіть **Конверти**.
2. На Кроці 2 натисніть **Змінити макет документа → Параметри конверта** і виберіть потрібний **Розмір конверта**.
3. На Кроці 3 оберіть **Наявний список → Огляд**, підключіть файл Excel (наприклад, `Адреса.xlsx`, таблиця `Аркуш1$`).
4. На Кроці 4 вставте поля (`«Ім_я»`, `«Прізвище»`, `«Адреса»`) у ділянку адресата (внизу в центрі або в правому нижньому куті конверта).
5. Перегляньте конверти (Крок 5) і завершіть злиття через **Змінити окремі конверти** (Крок 6).
