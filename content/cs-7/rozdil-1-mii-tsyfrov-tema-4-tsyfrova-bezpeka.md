# Тема 4. Цифрова безпека (с. 30–39)

## 1. Безпека бездротової мережі
**Цифрова безпека** передбачає захист обладнання, мереж, програмного забезпечення та даних від несанкціонованого доступу.

| Варіант захисту Wi-Fi | Рівень безпеки та рекомендація |
| :--- | :--- |
| **Вимкнутий захист** | Дуже небезпечно: будь-хто під’єднається до мережі, сповільнить інтернет і зможе перехопити відкриті повідомлення, пошту й паролі. |
| **WEP** (*Wired Equivalent Privacy*) | Найстаріший стандарт; пароль зламується менш ніж за хвилину. **Уникати!** |
| **WPA** (*WiFi Protected Access*) | Виправив частину вразливостей WEP, але також застарілий. **Уникати!** |
| **WPA2** | Надійний стандарт, який підтримують усі сучасні роутери. Використовуйте, якщо немає WPA3. |
| **WPA3** | Найновіший і найзахищеніший стандарт шифрування. **Найкращий вибір** для домашньої мережі. |

## 2. Облікові записи користувачів у Windows
Якщо комп’ютером користується кілька людей, для кожного варто створити окремий обліковий запис із паролем (власний робочий стіл і приватні файли):
- **Користувач (стандартний)** — може користуватися програмами, інтернетом, поштою та документами. **Найкраща практика** для щоденної роботи.
- **Адміністратор** — має права на зміну системних налаштувань, встановлення/видалення програм і доступ до всіх файлів. Використовуйте лише тоді, коли це справді потрібно (щоб випадково не запустити вірус із правами адміністратора).

## 3. Шкідливе програмне забезпечення та заходи захисту
> **Шкідливе ПЗ** — програма або її частина, спеціально розроблена для заподіяння шкоди комп’ютеру чи даним.

| Тип загрози | Як діє та в чому особливість |
| :--- | :--- |
| **Комп’ютерний вірус** | Самовідтворюється (**реплікація**), заражає файли й програми, пошкоджує дані, сповільнює ПК. Для запуску зазвичай потрібне втручання людини (відкриття зараженого файлу з інтернету, пошти чи USB). |
| **Мережевий хробак** | Автономна програма, що сама таємно розсилає свій код мережею (зокрема через пошту). Не пошкоджує дані, але сповільнює мережу; використовується для розсилки **спаму** та **DoS/DDoS-атак** (перевантаження системи, щоб зробити її недоступною). |
| **Програма-вимагач (здирник)** | Шифрує файли користувача, після чого зловмисники вимагають гроші за відновлення доступу. |

> 📜 **Історія:** Перший вірус для смартфонів був створений у березні 2005 року під назвою **COMM warrior-A**.

### Як захистити пристрої та мережу?
1. Встановіть **антивірус** із автоматичним оновленням баз (у Windows вбудовано **Windows Defender**).
2. Увімкніть **брандмауер Windows** та отримуйте оновлення через **Windows Update**.
3. Увімкніть **Windows Defender SmartScreen** (*Налаштування → Оновлення та захист → Безпека у Windows → Керування програмами та браузерами → Захист на основі репутації*), щоб блокувати шахрайські сайти й небезпечні завантаження.
4. Використовуйте **VPN** (*Virtual Private Network* — віртуальна приватна мережа): шифрує дані та приховує IP-адресу, що особливо корисно в публічному Wi-Fi, але сповільнює з’єднання, тому обирайте лише надійних постачальників.
5. Під час встановлення мобільних застосунків: завантажуйте з офіційних магазинів, читайте відгуки, контролюйте **дозволи** (камера, мікрофон, контакти, геолокація) та налаштовуйте приватність.

## 4. Особиста безпека та конфіденційність у мережі
> **Автентифікація (верифікація)** — підтвердження того, що людина справді є тією, за кого себе видає.

- Створюйте складні паролі, періодично їх змінюйте й використовуйте **менеджери паролів**; ніколи не розголошуйте PIN-код і дані банківської картки.
- Вмикайте **двофакторну (2FA)** або **багатофакторну автентифікацію** (логін + пароль + код із SMS/застосунку, відбиток пальця, графічний ключ тощо).
- У соціальних мережах:
  - не робіть профіль публічним, перевіряйте налаштування приватності;
  - не публікуйте справжню адресу, номер телефону, назву школи чи фінансові дані;
  - «дружіть» лише з тими, кого знаєте особисто, і стежте, щоб вас не позначали на чужих світлинах без відома;
  - пам’ятайте: усе опубліковане в інтернеті може залишатися там назавжди (навіть після видалення), а у відеоіграх важливо дотримуватися поміркованості та берегти персональні дані.
