# Тема 3. Запис звуку (с. 192–196)

## 1. Знайомство з Audacity та базовий монтаж
**Audacity** (`audacityteam.org/download/`) — безкоштовна програма для запису й редагування аудіо (за замовчуванням проєкти зберігаються в теці *Документи / Audacity*).

- **Звукова хвиля** — коливання тиску в повітрі, що сприймається як звук (відображається на доріжці у вигляді графіка).
- **Запис голосу:** під’єднайте мікрофон → натисніть **Запис** (червоне коло) → після завершення натисніть **Зупинити**.
- **Відтворення та видалення:** виділіть мишею потрібний фрагмент і натисніть **Відтворити** (або клавішу `Space`), щоб прослухати; клавіша `Delete` видаляє виділений фрагмент.
- **Дублювання та переміщення:** виділіть фрагмент → **Копіювати** (`Ctrl + C`) або **Вирізати** (`Ctrl + X`) → клацніть у новому місці → **Вставити** (`Ctrl + V`).

## 2. Мікширування (змішування) та експорт аудіо
Щоб накласти голос на музику або поєднати кілька доріжок:
1. **Файл → Імпорт → Звукові дані** — додасться друга звукова доріжка під першою.
2. Натисніть `Space` для спільного прослуховування й відрегулюйте **гучність** доріжок повзунками ліворуч.
3. Збережіть готовий результат: **Файл → Експортувати звукові дані** → введіть назву, оберіть формат (наприклад, `MP3` чи `WAV`) → **Експорт**.

## 3. Корисні звукові ефекти в Audacity
| Ефект | Як застосувати | Результат |
| :--- | :--- | :--- |
| **Видалення шуму** | 1) Виділіть ділянку лише з шумом → *Ефекти → Вилучення шуму і відновлення → Зменшення шумності → Створити модель шуму*.<br>2) Виділіть весь звук → повторіть шлях → *Гаразд*. | Прибирає фоновий шум мікрофона з усього запису. |
| **Зміна швидкості** | *Ефекти → Зміна тону і темпу → Змінити швидкість і тон* → пересуньте повзунок (*Тест* → *Застосувати*). | Прискорення робить запис коротшим і тон вищим; сповільнення — довшим і нижчим. |
| **Повільне наростання / згасання** | Виділіть початок (або кінець) доріжки → *Ефекти → Згасання → Повільне наростання* (або *Повільне згасання*). | Плавне збільшення гучності на початку та плавне затихання в кінці. |
| **Вилучення вокалу** | Виділіть доріжку → *Ефекти → Усування та ізоляція вокалу → Застосувати*. | Видаляє голос співака/співачки для створення караоке-мінусівки. |

## 🧠 Запитання для самоперевірки

2. Чим **Імпорт звукових даних** відрізняється від **Експорту звукових даних**?
3. Опиши двоетапний алгоритм **видалення шуму** в Audacity.
4. Як ефект **Змінити швидкість і тон** впливає на тривалість і звучання аудіокліпу?
5. Для чого застосовують ефекти **Повільне наростання / згасання** та **Усування та ізоляція вокалу**?
