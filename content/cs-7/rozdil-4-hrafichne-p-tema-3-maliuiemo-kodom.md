## 1. Створення графічного вікна в pygame
> **Піксель** — найменша точка екрана комп’ютера.

| Команда | Опис |
| :--- | :--- |
| `import pygame` | Імпортує всі модулі, що належать до `pygame` |
| `pygame.init()` | Ініціалізує імпортований модуль `pygame` |
| `screen = pygame.display.set_mode((800, 600))` | Відкриває вікно шириною `800` і висотою `600` пікселів |
| `Teal = (0, 128, 128)` | Визначає змінну кольору в системі RGB |
| `screen.fill(Teal)` | Заповнює все вікно заданим кольором |
| `pygame.display.update()` | Оновлює вміст вікна (відображає всі зміни разом, щоб уникнути мерехтіння) |

## 2. Геометричні примітиви в `pygame.draw`
> **Геометричний примітив** — найпростіша базова геометрична форма (точка, лінія, коло, квадрат тощо), із якої створюють складні зображення.

| Фігура | Синтаксис команди | Пояснення параметрів |
| :--- | :--- | :--- |
| **Лінія** | `pygame.draw.line(screen, color, (x1, y1), (x2, y2), width)` | `(x1, y1)` — початок, `(x2, y2)` — кінець, `width` — товщина пера |
| **Ламана / Трикутник** | `pygame.draw.lines(screen, color, True, [(x1, y1), (x2, y2), (x3, y3)], width)` | `True` — замкнута ламана (утворює трикутник), `False` — незамкнута |
| **Прямокутник** | `pygame.draw.rect(screen, color, (x, y, width, height), line_width)` | `(x, y)` — лівий верхній кут; якщо `line_width == 0`, фігура **зафарбована** |
| **Коло** | `pygame.draw.circle(screen, color, (x, y), radius, width)` | `(x, y)` — центр кола, `radius` — радіус; `width == 0` — суцільний круг |
| **Еліпс** | `pygame.draw.ellipse(screen, color, (x, y, rect_w, rect_h), width)` | Вписується у прямокутник із координатами `(x, y)` і розмірами `rect_w × rect_h` |

> 📜 **Цікавий факт:** Мова **Python** названа не на честь змії, а на честь британського комедійного скетч-шоу **«Літаючий цирк Монті Пайтона»**.
