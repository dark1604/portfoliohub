# Тема 4. Обробка зображень (с. 197–201)

## 1. Перегляд зображень у Microsoft Photos
**Microsoft Photos** — безкоштовна вбудована програма Windows для перегляду та базового редагування фотографій (для складнішого професійного редагування використовують *Adobe Photoshop*).
- **Масштабування:** повзунок масштабу, комбінації `Ctrl + +` / `Ctrl + -` або `Ctrl` + коліщатко миші.
- **Навігація та слайд-шоу:** стрілки *Далі* / *Назад*; кнопка **Почати показ слайдів** або **`F5`** (вихід — подвійний клік `Esc` або *Вийти з показу слайдів*).

## 2. Основні інструменти редагування фото
Натисніть **Редагувати зображення** на верхній панелі:

| Інструмент | Призначення та дії |
| :--- | :--- |
| **Ретуш** | Видалення дрібних плям і дефектів: вкладка *Ретушувати* → вибір розміру пензля → клік по дефекту. |
| **Повертання** | Кнопка *Повернути* повертає фото за годинниковою стрілкою на **90°**. |
| **Обтинання** | Перетягування кутів сітки для видалення зайвих країв (затінена частина вирізається). |
| **Зміна форми (пропорцій)** | На панелі *Обітнути* натисніть *Довільні* й оберіть пропорцію (наприклад, **3 : 4**) → *Готово*. |
| **Відбиття** | На вкладці *Обітнути* натисніть *Відбити зображення по горизонталі* (дзеркальне відображення). |
| **Фільтри та покращення** | Вкладка *Фільтр* → *Автоматичне покращення* або художні фільтри (*Ч&Б прохолодний* — відтінки сірого, *Сепія* — ефект старого фото, *Різкий прохолодний* — синій відтінок) + повзунок *Інтенсивність*. |

> 💡 **Збереження змін:**
> - **Зберегти як копію** — створює новий файл, залишаючи оригінал недоторканим (рекомендовано!).
> - **Зберегти** — перезаписує поточний файл.
> - **Скасувати все** — відміняє всі внесені зміни.
> - Регулярно робіть **резервні копії** файлів, над якими працюєте!
