# Тема 5. Створення відео (с. 202–207)

## 1. Початок роботи в Microsoft Clipchamp
**Microsoft Clipchamp** — зручний відеоредактор, доступний як програма для ПК/смартфона або онлайн-вебсервіс (`clipchamp.com`). Не забувайте про **авторське право**, використовуючи чужі фото, відео чи музику!

**Додавання медіа та часова шкала:**
1. Натисніть **Створити нове відео** й уведіть назву проєкту.
2. У розділі **Ваші медіа → Імпорт мультимедіа → Огляд файлів** завантажте потрібні фото, відео й аудіо.
3. Перетягніть файли на **часову шкалу редактора** (вона має кілька рядків-доріжок). Порядок кліпів змінюють перетягуванням.
4. **Тривалість показу фото:** потягніть за праву межу світлини на часовій шкалі вліво або вправо.
5. **Видалення порожніх проміжків:** клацніть правою кнопкою миші по проміжку на часовій шкалі → *Видалити цей проміжок* (або *Видалити всі візуальні прогалини*).

## 2. Ефекти, переходи, фільтри, музика та текст
| Інструмент | Де знайти і як налаштувати |
| :--- | :--- |
| **Ефекти** | Виділіть кадр → права панель **Ефекти** → оберіть ефект і відрегулюйте інтенсивність/швидкість. |
| **Переходи** | Наведіть курсор на стик між кадрами, доки не з’явиться **`+`** → клікніть → оберіть ефект на панелі **Перехід** і налаштуйте тривалість. |
| **Фільтри** | Виділіть кадр → права панель **Фільтри** → оберіть художній фільтр та його інтенсивність. |
| **Музика** | Ліва панель **Бібліотека вмісту → Аудіо → Музика / Звукові ефекти** → **`+`** (або власне аудіо з *Ваші медіа*). Обріжте початок і кінець звуку під відео. |
| **Текст / Титри** | Ліва панель **Текст → Текст** або анімований **Заголовок** → **`+`** → на правій панелі змініть напис, шрифт, розмір, колір, розташування та час показу на шкалі. |

## 3. Редагування (розрізання) відео та експорт
### Як вирізати невдалий («ляп») або зайвий фрагмент?
1. Установіть маркер (бігунок) на лінії часу на **початок** зайвого епізоду → натисніть **Розділити**.
2. Перемістіть маркер на **кінець** зайвого епізоду → знову натисніть **Розділити**.
3. Клацніть по відокремленому фрагменту й натисніть **Видалити (`DEL`)** (і видаліть утворений проміжок).

### Експорт і поширення
Натисніть **Експорт** і оберіть якість:
- **`1080p` (Висока якість)** — для збереження на ПК, перегляду на великих екранах;
- **`720p`** — оптимально для швидкого розміщення на вебсайті;
- **`GIF`** — для коротких циклічних анімацій (до 15 секунд).
- Готове відео можна зберегти на диск, у хмару (*OneDrive*, *Google Диск*, *Dropbox*), завантажити на *YouTube* / *TikTok* або натиснути **Створити посилання на відео** у хмарі Clipchamp.
