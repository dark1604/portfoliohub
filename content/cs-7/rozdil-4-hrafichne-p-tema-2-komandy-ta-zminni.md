# Тема 2. Команди та змінні (с. 136–139)

## 1. Змінні та типи даних
> **Змінна** — іменований контейнер (ярлик) для зберігання даних, значення якого можна змінювати під час роботи програми.

Основні типи даних у Python:
- **Цілі числа:** `56`, `-98`, `35`
- **Десяткові дроби (через крапку):** `1.89`, `-95.45`
- **Рядки (текст у прямих лапках `"` або `'`):** `"Сьогодні температура 16 градусів."` (фігурні лапки `“` чи `”` спричинять помилку!).

**Правила іменування змінних:**
- може починатися з літери або підкреслення (`A-z`, `_`), **не може** починатися з цифри;
- містить лише літери, цифри та `_`;
- залежить від регістру (`age`, `Age`, `AGE` — три різні змінні);
- не може збігатися із **зарезервованими словами** (`print`, `return`, `while`, `True`, `False`, `else`, `and`, `not`, `import`, `None`, `global`, `break`);
- назва має бути описовою (наприклад, `total_volume`, `birth_year`).

## 2. Виведення, рядки та списки
- **`print()`** — функція виведення даних на екран.
- Підстановка змінної в рядок за допомогою `%`:
  ```python
  i = 16
  message = "Сьогодні температура %s градусів."
  print(message % i)
  ```
- **Список** — змінна для зберігання набору елементів. Нумерація індексів починається з **0**!
  ```python
  season_list = ["осінь", "зима", "весна", "літо"]
  print(season_list[3])  # Виведе: літо
  ```

## 3. Введення даних (`input()`) та арифметичні операції
- **`input()`** зупиняє програму й чекає введення даних від користувача. За замовчуванням повертає **рядок**.
- Щоб отримати **ціле число**, використовують перетворення **`int(input())`**:
  ```python
  sound_speed = 340
  time = int(input("Скільки секунд ви нарахували між спалахом блискавки та ударом грому? "))
  distance = time * sound_speed
  ```
- **Арифметичні оператори:** `+` (додавання), `-` (віднімання), `*` (множення — у коді обов’язково писати `x*y`, а не `xy`), `/` (ділення).

> 🚀 **Цікавий факт:** Мова Python використовується в **NASA** для математичних розрахунків параметрів польоту.

## 4. Функції та коментарі
> **Функція** — блок інструкцій, який виконує певну дію і після визначення за допомогою ключового слова **`def`** може викликатися багаторазово.

```python
def sum(a, b):   # a, b — параметри
    c = a + b
    return c

print(sum(3, 5)) # 3, 5 — аргументи; виведе 8
```

> **Коментарі** починаються із символу **`#`** і діють до кінця рядка. Вони не виконуються комп’ютером, але пояснюють код людям.
