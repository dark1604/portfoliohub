# Тема 2. Формати медіафайлів (с. 185–191)

## 1. Типи та розширення медіафайлів
Розширення після крапки в назві файлу (наприклад, `моя_школа.jpg`) вказує на його тип:

| Тип файлу | Поширені розширення |
| :--- | :--- |
| **Растрове зображення / фото** | `.jpg`, `.png`, `.gif`, `.bmp`, `.tif` |
| **Векторний малюнок** | `.ai`, `.eps`, `.svg`, `.dwg` |
| **Аудіофайл** | `.wav`, `.wma`, `.mp3`, `.aac` |
| **Відеофайл** | `.avi`, `.wmv`, `.mpg`, `.mp4`, `.mkv`, `.3gp`, `.mov` |

> ⚠️ **Бережіть себе:** Під час тривалої роботи за клавіатурою робіть перерви, щоб запобігти **тунельному синдрому зап’ястя**.

---

## 2. Відеофайли: роздільна здатність, кодеки та контейнери
- **Роздільна здатність:** **SD** (стандартна), **HD** (висока), **4K** (~4000 пікселів по горизонталі), **UHDTV**, **5K**, **16K**. Що вища роздільна здатність — то чіткіше відео й більший розмір файлу.
- **Кодек** — програма/алгоритм, що стискає (кодує) відео для меншого обсягу та розкодовує для перегляду (популярні кодеки: **MPEG-4**, **VC-1/VC-3**, **H.264/H.265**). Якщо відео не відкривається, встановіть плеєр **VLC** або пакет кодеків.
- **Контейнер** — оболонка файлу, що об’єднує відео, аудіо та субтитри (саме тип контейнера показує розширення: **AVI** `.avi`, **Matroska** `.mkv`, **MP4** `.mp4`/`.m4v`, **QTFF** `.mov`/`.qtff`).

---

## 3. Аудіофайли: якість, частота дискретизації та бітрейт
- **Нестиснутий формат (`WAV`)** — еталонна якість без втрат, але великий обсяг файлу.
- **Стиснуті формати (`MP3`, `WMA`, `OGG`)** — значно менший розмір із незначною втратою якості.
- **Частота дискретизації** — визначає точність і якість звуку (**44,1 кГц** — стандарт для музики; **22,05 кГц** — достатньо для голосу).
- **Бітрейт** — швидкість передачі даних (ступінь стиснення): для музики радять **192–320 кбіт/с** (нижче **128 кбіт/с** втрата якості вже помітна), для голосу — **64–128 кбіт/с**.

> ⚠️ **Бережіть себе:** Не вмикайте занадто високу гучність у навушниках, щоб не пошкодити слух.

---

## 4. Растрові зображення, пікселі та імпорт медіа
> **Пікселі** — крихітні кольорові квадратики, із яких, наче з мозаїки, складається растрове зображення (камера 14 Мп формує зображення з 14 мільйонів пікселів; окрім мегапікселів, на якість фото сильно впливає **об’єктив**).

| Формат | Особливості та призначення |
| :--- | :--- |
| **JPEG** (`.jpg`) | Стиснення з незначною втратою якості, малий розмір. Стандарт для фотоапаратів, смартфонів, вебсайтів, пошти. |
| **TIFF** (`.tif`) | Нестиснутий або без втрат; найвища якість, великий розмір. Для професійного друку й поліграфії. |
| **GIF** (`.gif`) | Підтримує прозорість і анімацію, мало кольорів. Для вебграфіки, не для фото. |
| **PNG** (`.png`) | Підтримує прозорість, гарна якість і невеликий розмір. Універсальний формат для інтернету й презентацій. |

**Імпорт медіа:** під’єднайте камеру/смартфон через **USB-кабель** або вставте карту пам’яті в **кардридер** → у вікні *Автовідтворення* оберіть **Відкрити папку** → скопіюйте або виріжте файли на комп’ютер.

3. Яку частоту дискретизації та бітрейт краще обрати для запису музики, а яку — для голосу?

5. Коли краще використовувати формат **PNG**, а коли — **JPEG** чи **TIFF**?
