## 1. Цикл `for` і функція `range()`
Щоб не повторювати однаковий код десятки разів, у програмуванні використовують **цикли** — конструкції, що багаторазово виконують певний блок команд.

- **Цикл `for`** використовують, коли **кількість повторень відома** (фіксована).
- Блок коду всередині циклу обов’язково записується з **відступом** (4 пропуски).
- Функція **`range(start, stop, step)`** задає діапазон для змінної-**лічильника** (`stop` не включається!):
  - `range(5)` → `0, 1, 2, 3, 4` (початок за замовчуванням `0`, крок `+1`);
  - `range(2, 5)` → `2, 3, 4`;
  - `range(1, 5, 2)` → `1, 3` (крок `2`);
  - `range(10, 5, -2)` → `10, 8, 6` (зворотний відлік із від’ємним кроком).

```python
for i in range(10):
    pygame.draw.line(screen, yellow, (20, i * 15), (180, i * 15), 2)
```
Змінюючи координати чи товщину лінії за допомогою змінної `i`, отримуємо паралельні прямі, віяло ліній зі спільної точки або вкладені прямокутники.

## 2. Цикл `while`
- **Цикл `while`** використовують, коли **кількість повторень невідома** — він працює доти, доки умова істинна (**`True`**).
- Якщо умова одразу хибна (**`False`**), тіло циклу не виконається жодного разу.

```python
a = int(input("Введіть значення для a: "))
while a < 10:
    print(a)
    a = int(input("Введіть значення для a: "))
print("Цикл завершено.")
```

## 3. Будуємо дотичні та концентричні кола
- **Коло** — фігура, усі точки якої рівновіддалені від центра; **радіус** з’єднує центр із точкою на колі, а **діаметр** з’єднує дві точки кола через центр.
- Два кола мають **дотик** (одну спільну точку):
  - **зовнішній дотик** — центри лежать по різні боки від точки дотику (відстань між центрами дорівнює $r_1 + r_2$);
  - **внутрішній дотик** — центри лежать по один бік від точки дотику.
- **Концентричні кола** — кола зі спільним центром і різними радіусами (область між ними називається **кільцем**). Їх зручно малювати в циклі `for`:
  ```python
  for i in range(1, 125, 20):
      pygame.draw.circle(screen, green, (155, 155), i + 30, 2)
  ```

> 📜 **Історія:** Слово **баг** (англ. *bug* — жук, помилка) увійшло в ІТ у **1947 році**, коли справжня міль потрапила в реле комп’ютера Гарвардського університету. Адмірал **Ґрейс Гоппер** назвала її видалення *debugging* (налагодженням системи).
