# Тема 2. Колонтитули (с. 100–104)

## 1. Що таке колонтитули?
- **Верхній колонтитул** — один або кілька рядків тексту вгорі кожної сторінки над основним текстом (зазвичай назва документа, автор, дата).
- **Нижній колонтитул** — ділянка внизу кожної сторінки (зазвичай номери сторінок).

**Як додати в Microsoft Word:**
1. Вкладка **Вставлення → Колонтитули → Верхній колонтитул** (наприклад, *Пусто (три стовпці)*) або **Нижній колонтитул** (наприклад, *Смуги*).
2. Уведіть текст або вставте об’єкти (**Зображення**, **Дата й час**).
3. На вкладці **Конструктор** натисніть **Закрити колонтитули** (для швидкого редагування пізніше — двічі клацніть по ділянці колонтитула).

**Корисні параметри на вкладці Конструктор:**
- **Інші для першої сторінки** — дає змогу прибрати або змінити колонтитули на титульній сторінці.
- **Різні для непарних і парних сторінок** — окреме оформлення для лівих і правих сторінок (як у книжках).
- **Зберегти виділений фрагмент до колекції...** — зберігає власний колонтитул для повторного використання.

## 2. Нумерація сторінок та Дата й час
Коли ви додаєте **нумерацію сторінок**, ви фактично вставляєте верхній або нижній колонтитул:
- **Вставлення → Номер сторінки** → оберіть розташування (*Угорі сторінки*, *Внизу сторінки*, *На полях сторінки*, *Поточне положення*) та стиль (наприклад, *Звичайні цифри 3*).
- **Формат номерів сторінок** дає змогу обрати вигляд (`-1-`, `-2-`, `-3-`) або задати номер у полі **Почати з**.
- **Дата й час** (*Конструктор → Вставлення → Дата й час*): можна обрати формат (напр., `28.12.2023`) і поставити прапорець **Оновлювати автоматично**, щоб завжди відображалася поточна дата.

## 3. Відображення прихованих символів форматування
Іноді натискання клавіш змінює текст, але на екрані нічого не видно (пробіли, абзаци, розриви). Щоб побачити «спеціальні» недруковані символи, на вкладці **Основне** у групі **Абзац** натисніть **Відобразити всі знаки** (`¶`) або комбінацію **`Ctrl + *`**.

| Символ | Значення | Клавіша |
| :---: | :--- | :--- |
| `·` | Пропуск (пробіл) | `Пробіл` |
| `→` | Символ табуляції | `Tab` |
| `¶` | Символ кінця абзацу | `Enter` |
| `↵` | Символ кінця рядка | `Shift + Enter` |
| `....` (з підписом) | Розрив стовпця / сторінки / розділу | Вкладка *Макет → Розриви* |
