# Алгоритми пошуку та сортування масивів у Python

Ефективність роботи програми визначається тим, як швидко зростає кількість операцій при збільшенні розміру вхідних даних $n$. Для цього використовують асимптотичну нотацію **Big-O**.

## 1. Порівняння складності базових алгоритмів

| Алгоритм | Найкращий час | Середній час | Найгірший час | Пам'ять |
| :--- | :--- | :--- | :--- | :--- |
| Лінійний пошук | $O(1)$ | $O(n)$ | $O(n)$ | $O(1)$ |
| Бінарний пошук | $O(1)$ | $O(\log_2 n)$ | $O(\log_2 n)$ | $O(1)$ |
| Сортування бульбашкою | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ |
| Сортування вибором | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ |
| Timsort (`list.sort()`) | $O(n)$ | $O(n \log_2 n)$ | $O(n \log_2 n)$ | $O(n)$ |

## 2. Двійковий (бінарний) пошук

**Бінарний пошук** працює лише на **відсортованому** масиві. На кожному кроці ми ділимо інтервал пошуку навпіл, порівнюючи середній елемент `arr[mid]` із шуканим значенням `target`.

Максимальна кількість кроків для масиву з $n$ елементів становить:

$$k = \lfloor \log_2 n \rfloor + 1$$

> Для масиву з $1\,000\,000$ елементів бінарний пошук виконає щонайбільше **20 перевірок** замість мільйона!

```python
def binary_search(arr: list[int], target: int) -> int:
    """Повертає індекс елемента target або -1, якщо елемент не знайдено."""
    left = 0
    right = len(arr) - 1

    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1

data = [4, 12, 19, 25, 38, 42, 57, 81, 95]
index = binary_search(data, 42)
print(f"Елемент 42 знайдено на позиції: {index}")  # 5
```

## 3. Оптимізоване сортування бульбашкою (Bubble Sort)

Класичний алгоритм послідовно порівнює сусідні елементи $a_i$ та $a_{i+1}$ і міняє їх місцями, якщо $a_i > a_{i+1}$. Додавання прапорця `swapped` дозволяє завершити роботу достроково, якщо список уже впорядкований:

```python
def bubble_sort_optimized(arr: list[int]) -> list[int]:
    n = len(arr)
    result = arr.copy()

    for i in range(n - 1):
        swapped = False
        for j in range(0, n - i - 1):
            if result[j] > result[j + 1]:
                result[j], result[j + 1] = result[j + 1], result[j]
                swapped = True
        if not swapped:
            break
    return result

sample = [64, 34, 25, 12, 22, 11, 90]
print("Відсортовано:", bubble_sort_optimized(sample))
```
