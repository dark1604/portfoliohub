# Тема 1. Створення вебсторінки (с. 145–151)

## 1. Вебсайт і структура HTML5-документа
- **Вебсторінка** — документ гіпертексту, який відкривається у браузері. Сукупність пов’язаних сторінок утворює **вебсайт** (головна сторінка зазвичай має ім’я `index.html`), доступний за **доменним ім’ям**.
- **HTML** (*HyperText Markup Language*) — мова розмітки, що складається з **тегів** (парних `<p>...</p>` та непарних `<br>`).

### Базовий каркас HTML5:
```html
<!DOCTYPE html>
<html>
  <head>
    <title>Назва у вкладці</title>
  </head>
  <body>
    <!-- Коментар: видимий вміст сторінки -->
  </body>
</html>
```

## 2. Розмітка тексту, списки та атрибути
- **Заголовки:** `<h1>` (найбільший) – `<h6>` (найменший).
- **Абзац та перенесення:** `<p>`, `<br>` (новий рядок).
- **Виділення:** `<b>` (жирний), `<i>` (курсив), `<u>` (підкреслений).
- **Списки:**
  - Маркований `<ul>` з пунктами `<li>` (типи маркерів `type`: `disc`, `circle`, `square`).
  - Нумерований `<ol>` (`type`: `1`, `A`, `a`, `I`, `i`).
- **Атрибути** записують усередині відкриваючого тега (`атрибут="значення"`). Кольори задають назвою (`red`), HEX-кодом (`#ff0000`) або RGB (`rgb(255, 0, 0)`). У навчальних прикладах для кольору тексту інколи трапляється застарілий тег `<font>`, хоча в сучасній верстці для цього використовують CSS.

---

## 3. Таблиці в HTML
- `<table>` — контейнер таблиці; `<caption>` — заголовок таблиці; `<thead>` — шапка.
- `<tr>` — рядок таблиці; `<th>` — клітинка заголовка (жирна, по центру); `<td>` — звичайна клітинка даних.
