# Тема 4. Вебформи (с. 160–169)

## 1. Створення вебформ
**Вебформа** дозволяє користувачам вводити й надсилати дані на сервер (реєстрація, пошук, зворотний зв’язок).
- Контейнер форми: `<form action="handler.php" method="post">` (методи **`get`** — передає дані в URL, **`post`** — приховано в тілі запиту).
- **Поля введення:**
  - `<input type="text" name="username">` — однорядкове текстове поле;
  - `<input type="email" name="mail">` — поле для електронної пошти;
  - `<input type="submit" value="Надіслати">` — кнопка відправки;
  - `<textarea cols="30" rows="5"></textarea>` — багаторядкове текстове поле.
- Спеціальний символ `&nbsp;` вставляє нерозривний пробіл.

---

## 2. Двоколонковий макет і позиціювання
Для структурування сторінки використовують універсальні блоки **`<div>`**, наприклад:
- `#sidebar` (бічне меню) з `position: fixed; height: 100%;` — залишається закріпленим при прокручуванні;
- `#content` (основний вміст) з `margin: 0 0 0 222px; min-height: 100%;` — відступ зліва під ширину бічної панелі.
- Пункти меню роблять блочними (`display: block; text-decoration: none;`), додають реакцію на наведення курсора псевдокласом **`a:hover`** і позначають поточну сторінку класом **`.active`**.

---

## 3. Відступи (Box Model), обтікання та типи медіа
- **`margin`** — зовнішній відступ (навколо елемента); **`padding`** — внутрішній відступ (всередині рамки). Скорочений запис приймає від 1 до 4 значень (верх, право, низ, ліво — за годинниковою стрілкою).
- **`float: left;`** для `<img>` дозволяє тексту плавно обтікати зображення справа.
- **Типи медіа в CSS** задають різні стилі для екрана та друку: атрибут `media="print"` у `<link>` або правила `@media screen { ... }` і `@media print { ... }`.
