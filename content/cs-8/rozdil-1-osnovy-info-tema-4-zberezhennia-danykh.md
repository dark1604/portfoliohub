# Тема 4. Збереження даних (с. 25–29)

## 1. Пристрої та підготовка дисків до роботи
Для тривалого зберігання даних використовують **HDD**, **SSD**, **USB-накопичувачі** та **хмарні сховища**.

### Основні операції з дисками (*Керування дисками* у Windows):
- **Форматування** — створення файлової системи на диску (знищує попередні дані).
- **Створення та поділ на розділи** — логічне розділення фізичного диска (наприклад, для ОС і для особистих файлів).
- **Перевірка на помилки** та налаштування розміру **кластера**, стиснення чи шифрування.
- **Томи (RAID)** — об’єднання кількох дисків для підвищення швидкості або надійності зберігання.

---

## 2. Пошкодження дисків і профілактика
- **Фізичні (апаратні) пошкодження:** виникають через удари, перегрів, перепади напруги або зношування деталей. Для захисту від збоїв живлення використовують **ДБЖ** (джерело безперебійного живлення).
- **Логічні (програмні) пошкодження:** збої файлової системи, помилки запису, дії вірусів.
- Регулярне обслуговування у Windows виконується інструментом **Оптимізувати роботу дисків** (дефрагментація для HDD / TRIM для SSD).

---

## 3. Резервне копіювання та архівування
- **Резервне копіювання (бекап)** — створення копій важливих файлів на окремому носії або в хмарі на випадок втрати даних.
- **Архівування** — об’єднання одного чи кількох файлів в єдиний файл-архів зі стисненням (програми **7-Zip**, **WinRAR**).

---

## 4. Алгоритми стиснення даних
Стиснення дає змогу зменшити розмір файлів для економії місця та швидшої передачі мережею.
- **Стиснення без втрат** — дозволяє точно відновити початковий файл (формати **ZIP**, **GZIP**, **PNG**; алгоритми **LZW**, **DEFLATE**, **LZMA**, **Brotli**).
- **Стиснення з втратами** — відкидає малопомітні для людини деталі заради сильного зменшення розміру (формати **JPEG**, **MP3**).

### Класичні алгоритми перекодування:
- **Алгоритм Хаффмана** (метод «знизу вгору»): символи, що трапляються частіше, отримують коротші двійкові коди, а рідкісні — довші.
- **Алгоритм Шеннона–Фано** (метод «зверху вниз»): подібний до Хаффмана, але будує дерево кодів поділом множини символів згори донизу.
- **RLE (Run-Length Encoding)** — кодування повторів (зручне для простої графіки з великими однотонними ділянками, наприклад `AAAAA` → `5A`).
