# Тема 2. HTML та CSS (с. 152–156)

## 1. Вставлення відео в HTML5
- **Локальне відео:** тег `<video>` з вкладеним `<source>` та атрибутами керування: `controls` (панель плеєра), `autoplay`, `loop` (повтор), `muted` (без звуку).
- **Відео з YouTube:** вставляється через вбудований фрейм `<iframe>` (кнопка *Поділитися → Вставити* на YouTube).

## 2. Основи CSS та селектори
**CSS** (*Cascading Style Sheets*) — мова стилів, яка відповідає за зовнішній вигляд сторінки.
- **Синтаксис правила:** `селектор { властивість: значення; }` (наприклад, `background-color`, `color`, `padding`, `width`).
- **Кодування сторінки:** у `<head>` додають `<meta charset="UTF-8">`, щоб коректно відображалася кирилиця.

### Основні види селекторів:
1. **Селектор тега:** застосовується до всіх елементів цього типу (`p { color: blue; }`).
2. **Селектор класу (`.`):** застосовується до групи елементів з атрибутом `class="highlight"` (`.highlight { ... }`).
3. **Селектор ідентифікатора (`#`):** для одного унікального елемента з `id="header"` (`#header { ... }`).

---

## 3. Каскадність і зовнішні таблиці стилів
- **Каскадний ефект CSS:** стилі успадковуються, а при конфлікті перемагає специфічніше правило (`#id` важливіший за `.class`, а `.class` — за селектор тега) або правило, записане нижче.
- **Зовнішня таблиця стилів** — окремий файл (наприклад, `style.css`), що підключається в `<head>` один раз для всього сайту:
```html
<link href="style.css" rel="stylesheet" type="text/css">
```
