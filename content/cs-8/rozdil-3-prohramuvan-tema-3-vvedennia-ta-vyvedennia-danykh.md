# Тема 3. Введення та виведення даних (с. 104–106)

## 1. Присвоєння, введення та виведення
- Знак **`=`** у програмуванні означає **присвоєння** значення змінній (а не математичну рівність).
- **`input()`** — зчитує дані з клавіатури завжди у вигляді **рядка (`str`)**. Для обчислень текст перетворюють на число:
  - `int(input("Введіть ціле число: "))`
  - `float(input("Введіть дробове число: "))`
- **`print()`** — виводить значення, текст або результати виразів на екран.

---

## 2. Арифметичні операції та модуль `math`
Окрім стандартних `+`, `-`, `*`, `/`, у Python є:
- `//` — цілочисельне ділення (наприклад, `7 // 2 == 3`);
- `%` — остача від ділення (`7 % 2 == 1`);
- `**` — піднесення до степеня (`2 ** 3 == 8`).
- **Скорочені оператори присвоєння:** `+=`, `-=`, `*=`, `/=`, `%=`, `**=` (наприклад, `x += 5` означає `x = x + 5`).
- Вбудовані функції: `abs()`, `round()`, `pow()`, `max()`, `min()`, `len()`.
- Для складніших обчислень підключають модуль **`math`** (`import math`): `math.sqrt()` (корінь), `math.ceil()` (округлення вгору), `math.floor()` (униз), `math.factorial()`, `math.fmod()`.

## 3. Робота з рядками та коментарі
- **Конкатенація** — об’єднання рядків оператором **`+`**: `"Привіт, " + name`.
- **Коментарі** пояснюють код і не виконуються програмою:
  - однорядковий: `# це коментар`
  - багаторядковий: `''' багаторядковий коментар '''`

> ⚠️ **Важливо:** Не можна напряму додавати рядок і число (`"Вік: " + 14`) — спочатку перетворіть число на рядок функцією `str(14)` або передайте їх у `print("Вік:", 14)` через кому.
