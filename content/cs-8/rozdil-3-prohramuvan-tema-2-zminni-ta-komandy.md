# Тема 2. Змінні та команди (с. 99–103)

## 1. Структура програми на Python та змінні
Програма на Python зазвичай складається з таких блоків: імпорт модулів, глобальні змінні, визначення функцій і класів та основний код.
- **Змінна** — іменована область пам’яті для зберігання даних. Рядки беруть у одинарні `'` або подвійні `"` лапки.
- **Зарезервовані (ключові) слова** не можна використовувати як імена змінних: `print`, `return`, `while`, `True`, `False`, `else`, `and`, `not`, `import`, `None`, `global`, `break` тощо.

---

## 2. Типи даних у Python
- **Прості (базові):**
  - `int` — цілі числа (`10`, `-5`);
  - `float` — дробові числа (`3.14`);
  - `str` — текстові рядки (`"Привіт"`);
  - `bool` — логічні значення (`True` або `False`).
- **Складні (колекції):**
  - *Лінійні:* **список** (`list`), **кортеж** (`tuple`), **словник** (`dict`), **множина** (`set`).
  - *Нелінійні:* **дерево**, **граф**.

---

## 3. Робота зі списками (`list`)
**Список** — це впорядкована змінна колекція елементів у квадратних дужках `[...]`.
- **Індексація починається з `0`:** `MyList[2]` звертається до третього елемента.
- **Зрізи:** `MyList[2:5]` повертає елементи з індексами `2`, `3` і `4` (правий край не включається).
- **Вкладені списки:** список усередині списку; доступ до елемента: `matrix[2][1]`.

### Основні методи та функції для списків:
- `len(L)`, `sum(L)`, `max(L)`, `min(L)` — довжина, сума, максимум і мінімум.
- `L.append(x)` — додає елемент у кінець; `L.remove(x)` — видаляє за значенням; `del L[i]` — видаляє за індексом; `L.clear()` — очищує список.
- `L.count(x)` — рахує кількість входжень `x`; `L.sort()` — сортує; `L.reverse()` — розвертає порядок елементів.
