# Тема 1. Форматування тексту (с. 80–87)

## 1. Робоче середовище Microsoft Word
**Microsoft Word** — потужний текстовий процесор для набору, редагування та форматування тексту, побудови таблиць і додавання зображень.
- **Стрічка** у верхній частині містить вкладки (*Основне*, *Вставлення*, *Макет* тощо), де інструменти згруповані за призначенням (напр. *Шрифт*, *Абзац*). Стрічка є **динамічною** — при виборі зображення чи таблиці з’являються нові вкладки.
- **Лінійки** допомагають вирівнювати межі тексту.
- **Робоча область** — біла сторінка для введення тексту.
- Внизу справа — кнопки **режимів перегляду** та **повзунок масштабування**.

---

## 2. Набір тексту та робота з файлами
- **Правильне розташування рук:** ліва рука набирає ліворуч від клавіш `Е П И`, права — праворуч від `Н Р Т`. На клавіатурі є спеціальні мітки на клавішах **`А`** та **`О`**.
- **Корисні комбінації клавіш:**
  - `Ctrl + N` — створити новий документ;
  - `Ctrl + O` — відкрити документ;
  - `Ctrl + S` — зберегти документ (роби це регулярно!);
  - `Ctrl + W` — закрити поточний документ;
  - `Ctrl + A` — виділити **весь** текст у документі (подвійний клік виділяє одне слово).
- За замовчуванням Word зберігає файли у форматі **`.docx`**, але через **Файл → Зберегти як** можна обрати **`.pdf`**, `.html` чи звичайний текст.

## 3. Форматування шрифту (вкладка «Основне» → розділ «Шрифт»)
> 💡 **Головне правило:** спочатку **виділи** потрібний текст, а потім натискай кнопку форматування!

Основні інструменти розділу **Шрифт**:
- **Шрифт** і **Розмір шрифту**;
- **Напівжирний** (`Ctrl + B`), **Курсив**, **Підкреслення** (`Ctrl + U`), **Закреслення**;
- **Надрядковий** ($x^2$) та **Підрядковий** ($x_2$) символи;
- **Регістр** (зміна ВЕЛИКИХ / маленьких літер);
- **Колір тексту** та **Колір виділення тексту** (маркер).

## 4. Списки, вирівнювання та форматування абзацу
**Абзац** — сукупність речень, поєднаних за змістом; новий абзац починається після натискання `Enter`.

### Вкладка «Основне» → розділ «Абзац»:
- **Списки:** **Маркери** (крапки/символи) або **Нумерація** (`1, 2, 3…`).
- **Вирівнювання тексту:**
  - За лівим краєм (`Ctrl + L`);
  - По центру (`Ctrl + E`);
  - За правим краєм (`Ctrl + R`);
  - За шириною (`Ctrl + J` — рівні краї з обох боків).
- **Відступ абзацу:** кнопки **Збільшити / Зменшити відступ** або клавіша `Tab` на початку першого рядка.
- **Міжрядковий інтервал:** напр. `1.0`, `1.15`, `1.5`, `2.0`, а також *Додати / Видалити інтервал перед/після абзацу*.
- **Межі та заливка:** кнопка **Заливка** (колір фону за текстом) і **Межі** (напр. *Зовнішні межі* навколо абзацу).
