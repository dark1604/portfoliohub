# Тема 5. Онлайн-безпека (с. 72–76)

## 1. Комп’ютерні віруси та шкідливі програми
**Комп’ютерний вірус** — це програма, яка може поширюватися з одного комп’ютера на інший, щоб зашкодити роботі системи, видалити чи викрасти файли.

### Основні види шкідливого ПЗ:
- **Троянський кінь** — маскується під звичайну корисну програму, але дає хакеру таємний доступ до комп’ютера або краде дані.
- **Комп’ютерний хробак** — самостійно поширюється на інші комп’ютери переважно через мережу.
- **Шпигунські програми** — приховано збирають інформацію про користувача без його відома.
- **Рекламні програми** — без дозволу показують нав’язливу рекламу у спливаючих вікнах.

**Як віруси потрапляють на ПК?** Через вкладені файли й підозрілі посилання в листах від незнайомців або через «слабкі місця» в мережі.

---

## 2. Небезпечні повідомлення
- **Спам** — небажані масові листи (реклама або посилання з вірусами), що розсилаються тисячам людей.
- **Фішинг** — шахрайські повідомлення, які заманюють на підроблений (фейковий) сайт, щоб викрасти **логін, пароль або номер банківської картки**.
- **Лист щастя («магічне повідомлення»)** — лист із сумною історією чи обіцянкою удачі, який просить переслати його друзям. Його справжня мета — зібрати адреси для розсилки спаму.

---

## 3. Як захистити свій комп’ютер?
1. **Антивірус** (напр. вбудований **Безпека у Windows / Windows Security**):
   - *Пуск → Безпека у Windows → Захист від вірусів і загроз → Швидка перевірка*.
   - Обов’язково оновлюй антивірус та всі програми на комп’ютері!
2. **Брандмауер** (*Безпека у Windows → Брандмауер і захист мережі*) — контролює передачу даних у мережі та не пускає підозрілі програми в інтернет без твого дозволу. **Вимикати брандмауер не рекомендується!**
3. **Безпечне з’єднання (піктограма замка 🔒):**
   - Замок біля адреси сайту (`https://`) означає, що дані між тобою і сайтом **зашифровані**.
   - **Але увага:** замок не гарантує, що сайт чесний — вводь особисті дані лише на перевірених сайтах, яким довіряєш!

## 4. Як створити надійний пароль?
- Мінімум **8 символів** (пароль із 4 символів зламують дуже швидко).
- Не використовуй прості слова (*мама, тато, футбол*), свій логін, дату народження чи номер телефону.
- Поєднуй **великі/малі літери, цифри та символи** (наприклад, замість `markodigitalkids` зроби `m@rk0d!g!t@lk1ds`).
- **Не використовуй один і той самий пароль усюди** і ніколи не залишай папірець із паролем біля монітора.
- Для важливих акаунтів змінюй пароль кожні **6–12 місяців**.

## 🧠 Запитання для самоперевірки
1. Чим **троянський кінь** відрізняється від **комп’ютерного хробака**?
2. Що таке **фішинг** і чому не можна вводити пароль, перейшовши за підозрілим посиланням із листа?
3. Чи достатньо лише наявності значка **замка** біля адреси сайту, щоб довіряти йому свої дані?
4. Придумай приклад надійного пароля за правилами підручника (не використовуй його для реальних сайтів).
