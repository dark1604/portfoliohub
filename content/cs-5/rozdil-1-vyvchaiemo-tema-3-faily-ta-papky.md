# Тема 3. Файли та папки (с. 23–31)

## 1. Файл, папка та деревоподібна структура
- **Файл** — це сукупність даних на носії інформації (текст, фото, відео, музика тощо), створена за допомогою програм.
- **Папка** — місце для впорядкованого зберігання файлів. Папка може містити інші папки — їх називають **вкладеними**.
- Структура папок нагадує стовбур дерева з гілками (наприклад: `Моє ім’я → Завдання → З історії / З математики`).

> 💡 **Порада:** Завжди називай файли та папки зрозуміло відповідно до вмісту (наприклад, *Твір*, *План*, *Проєкт*, *Розклад*).

### Як створити папку:
- **На Робочому столі:** права кнопка миші на вільному місці → **Створити → Папку** → введи назву → `Enter`.
- **Усередині іншої папки (Провідник):** відкрий потрібну папку (напр. *Документи*) → натисни кнопку **Створити папку** → введи назву → `Enter`.

---

## 2. Копіювання, переміщення, видалення та пошук
| Дія | Меню (права кнопка миші) | Клавіші |
| :--- | :--- | :--- |
| **Копіювати** (залишає оригінал і робить копію) | Копіювати | `Ctrl + C` |
| **Вирізати** (переносить у нове місце) | Вирізати | `Ctrl + X` |
| **Вставити** | Вставити | `Ctrl + V` |
| **Перейменувати** | Перейменувати | `F2` |
| **Виділити кілька об’єктів** | — | `Ctrl + клік мишею` |

### Корисні прийоми:
- **Перетягування мишею:** якщо тягнути файл між вікнами **в межах одного диска** — файл **переміщується**; якщо утримувати `Ctrl` або тягнути **на інший диск** (напр. на флешку) — файл **копіюється**.
- **Швидке копіювання на флешку:** права кнопка миші по файлу/папці → **Надіслати → USB-дисковод**.
- **Пошук файлу чи папки:** у Провіднику в правому верхньому куті в полі **Пошук** введи назву об’єкта.

---

## 3. Ярлики
**Ярлик** — це посилання на файл, папку або програму для швидкого доступу (зазвичай має маленьку стрілочку в лівому нижньому куті).
- **Створити ярлик на Робочому столі:** права кнопка миші на файлі → **Надіслати → Робочий стіл (створити ярлик)**.
- **Важливо:** якщо видалити **ярлик**, зникає лише сам ярлик — **оригінальний файл чи програма залишаються цілими!**

---

## 4. Стиснуті папки (архіви ZIP)
Щоб зменшити розмір файлів перед пересиланням поштою або копіюванням, використовують **стиснення**.
- **Створити ZIP-папку:** права кнопка миші на файлі/папці → **Надіслати → Стиснута папка**.
- **Видобути (розпакувати) усе:** права кнопка миші на стиснутій папці → **Видобути все… → обери папку → Видобути**.
- **Чому не все стискається однаково?** Текстові файли стискаються дуже добре, а зображення у форматі `JPEG` уже стиснуті заздалегідь, тому їхній розмір майже не зменшиться.
- *З історії:* Формат **ZIP** створив Філіп Кац у 1989 році (назву «zip» — *швидкість* — придумав його друг Роберт Махоні).

---

## 5. Відображення файлів та Кошик
- **Макет у Провіднику** (**Вигляд → Макет**): Величезні, Великі, Середні або Дрібні піктограми, Список, Таблиця, Плитка, Вміст.
- **Деталі файлу:** **Вигляд → Сортувати за → Вибрати стовпці** (можна додати дату зміни, тип, розмір і змінювати порядок кнопками *Вгору* / *Вниз*).
- **Кошик:** видалені з жорсткого диска файли потрапляють у **Кошик**. Звідти їх можна **Відновити** або остаточно видалити (**Очистити кошик**).

## 🧠 Запитання для самоперевірки
1. Чим команда **Копіювати** (`Ctrl+C`) відрізняється від **Вирізати** (`Ctrl+X`)?
2. Що станеться, якщо видалити ярлик гри з Робочого стола? Чи видалиться сама гра?
3. Як швидко скопіювати презентацію на USB-флешку?
4. Чому файл `.txt` у ZIP-архіві стискається сильніше, ніж фото `.jpg`?
