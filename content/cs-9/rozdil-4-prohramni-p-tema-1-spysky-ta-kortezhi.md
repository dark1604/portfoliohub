# Тема 1. Списки та кортежі (с. 87–92)

## 1. Списки (`list`) у Python

> 📌 **Список (`list`)** — це впорядкована, змінювана колекція елементів будь-якого типу (числа, рядки, логічні значення, інші списки), що записується у квадратних дужках `[ ]`.

```python
fruits = ["яблуко", "банан", "вишня"]
number = [1, 2, 3, 4, 5]
mix = [1, "текст", True, 3.14]
```

### Індексація та зрізи
У кожного елемента є порядковий номер (**індекс**), починаючи з `0`:

| Індекс | `0` | `1` | `2` | `3` | `4` |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Елемент** | `"вареники"` | `"піца"` | `"суші"` | `"гречка"` | `"борщ"` |

```python
MyFavFood = ["вареники", "піца", "суші", "гречка", "борщ"]
print(MyFavFood[0])     # вареники
print(MyFavFood[4])     # борщ
print(MyFavFood[1:4])   # ['піца', 'суші', 'гречка']
print(MyFavFood[:3])    # ['вареники', 'піца', 'суші']
print(MyFavFood[2:])    # ['суші', 'гречка', 'борщ']
```

### Додавання, видалення та пошук елементів
- `append(x)` — додає елемент у кінець списку.
- `insert(i, x)` — вставляє елемент на позицію `i`.
- `remove(x)` — видаляє перше входження за значенням.
- `pop(i)` — видаляє елемент за індексом (або останній) і повертає його.
- `del my_list[i]` — видаляє елемент за індексом.
- `index(x)` — повертає індекс першого входження; `x in my_list` — перевіряє наявність (`True`/`False`).

```python
MyFavFood = ["вареники", "піца", "суші", "гречка", "борщ"]
MyFavFood.append("морозиво")
MyFavFood.insert(2, "салат")
MyFavFood.remove("піца")
LastFood = MyFavFood.pop()
del MyFavFood[0]
print("гречка" in MyFavFood)  # True
```

### Основні методи та функції списків
- `len(lst)` — кількість елементів; `sum(lst)` — сума; `min(lst)` / `max(lst)` — мінімум / максимум; `count(n)` — кількість входжень `n`.
- `reverse()` — розвертає список на місці; `sort()` — сортує; `extend(other)` — додає елементи іншого списку; `copy()` — копіює список; `list()` — перетворює інший тип у список.

## 2. Кортежі (`tuple`)

> 📌 **Кортеж (`tuple`)** — це впорядкована, **незмінна** колекція елементів, що записується у круглих дужках `( )`. Назва походить із математики (*n-кортеж*).

```python
coordinates = (10, 20)
color = ("червоний", "зелений", "синій")
oneElement = (42)
print(coordinates)  # (10, 20)
```

| Властивість | Список (`list`) | Кортеж (`tuple`) |
| :--- | :---: | :---: |
| **Дужки** | `[ ]` | `( )` |
| **Змінюваність** | Так | **Ні** |
| **Швидкість обробки** | Повільніше | **Швидше** |
| **Використання** | Для динамічних даних | Для постійних даних |

---

## 3. Словники (`dict`)

> 📌 **Словник (`dict`)** — це структура даних, яка зберігає пари **«ключ → значення»** у фігурних дужках `{ }` і забезпечує **семантичний доступ** (за іменем/ідентифікатором, а не за позицією).

```python
PhoneBook = {"Андрій": "011111111", "Марія": "022222222", "Оксана": "033333333"}
print(PhoneBook["Марія"])        # 022222222
PhoneBook["Ігор"] = "044444444"  # додавання нової пари
PhoneBook["Оксана"] = "05555555" # зміна значення
del PhoneBook["Андрій"]          # видалення запису
```

**Корисні функції та методи словників:** `len()`, `sorted()` (відсортований список ключів), `keys()` (ключі), `values()` (значення), `clear()` (очищення), `all()`, `any()`.
