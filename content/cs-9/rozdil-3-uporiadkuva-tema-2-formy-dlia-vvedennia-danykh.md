# Тема 2. Форми для введення даних (с. 65–68)

## 1. Навіщо потрібні форми?

> 📌 **Форма** — це зручний користувацький інтерфейс для додавання, перегляду та редагування даних у таблиці бази даних без прямого доступу до самої таблиці.

---

## 2. Створення форми за допомогою Майстра форм

1. Закрийте всі відкриті об’єкти та виділіть потрібну таблицю на панелі **Таблиці** (наприклад, *Учні*).
2. Перейдіть на вкладку **Створення → Форми → Майстер форм**.
3. Натисніть `>>`, щоб додати всі поля; видаліть `ID_учня` кнопкою `<` (оскільки воно заповнюється автоматично).
4. Натисніть **Далі**, оберіть макет (наприклад, **Стовпці**), задайте назву форми та натисніть **Готово**.

---

## 3. Робота із записами у формі

У нижній частині форми розташована панель навігації:
- перехід до **Першого**, **Попереднього**, **Наступного**, **Останнього** запису;
- відображення номера **Поточного** запису;
- кнопка **Створити новий запис**.

> 💡 **Підказка:** для швидкого переходу між полями натискайте клавішу `Tab`. Натискання `Tab` в останньому полі автоматично створює новий запис.

- **Зберегти запис:** *Основне → Записи → Зберегти*.
- **Видалити запис:** клацніть селектор запису зліва → *Основне → Записи → Видалити → Видалити запис → Так*.
  - ⚠️ При видаленні запису з полем `Автонумерація` його номер не використовується повторно (якщо видалити запис `4`, наступний отримає номер `5`).

---

## 4. Персоналізація форми

Щоб змінити вигляд форми, перейдіть у **Режим розмітки** (*Основне → Подання → Режим розмітки*):
- можна перетягувати поля та змінювати їхній розмір;
- у вкладці **Конструктор макетів форм → Знаряддя → Аркуш властивостей** можна змінити **Джерело елемента керування** (вкладка *Усі*), щоб пов’язати текстове поле з іншим полем таблиці;
- через **Елементи керування → Підпис** можна додавати заголовки (наприклад, *«Контактна інформація»*) та змінювати розмір і стиль шрифту в **Аркуші властивостей**.

> 💡 Форми мають бути максимально простими й зрозумілими, адже саме з ними найчастіше працюють користувачі бази даних.

## 🧠 Запитання для самоперевірки
1. Чому дані краще вводити через форму, а не безпосередньо в таблицю?
2. Чому поле `ID_учня` (Автонумерація) зазвичай не включають у форму?
3. Що відбувається з нумерацією `Автонумерації`, якщо видалити останній запис у таблиці?
4. Для чого використовують *Режим розмітки* та *Аркуш властивостей* при роботі з формою?
