# Тема 1. Моніторинг і керування (с. 7–12)

## 1. Системи моніторингу та керування

**Система моніторингу** призначена для спостереження та передавання даних на сервер, мережевий пристрій або іншу систему. Спостереження здійснюється за допомогою **датчиків**, дані з яких синхронізуються, аналізуються та надсилаються далі (приклад — охоронна сигналізація).

> 📌 **Система керування** — це сукупність взаємопов’язаних компонентів, які здатні керувати процесом або змінною.

> 📌 **Системи моніторингу й керування** — це системи, які відстежують середовище і керують ним. Вони використовують апаратні засоби: **датчики** — для моніторингу, **виконавчі механізми** — для керування.

### Типи систем керування

| Характеристика | Система з відкритим контуром | Система із замкнутим контуром |
| :--- | :--- | :--- |
| **Зворотний зв’язок** | Системи **без** зворотного зв’язку | Система **зі** зворотним зв’язком |
| **Вплив результату** | Вихідний результат не впливає на вхідні дані | На виході фіксується результат і використовується як зворотний зв’язок для саморегулювання |
| **Порівняння значень** | Немає порівняння між фактичними та бажаними значеннями | Відстежує вихідні значення й повертає частину інформації назад |
| **Адаптивність** | Погано пристосована до зміни умов | Призначена для автоматичного досягнення та підтримки заданих умов |
| **Приклад із підручника** | **Пральна машина** (брудний одяг → процес прання → чистий одяг) | **Кондиціонер** (бажана температура ↔ датчик температури → порівняння → керування приводом → увімкнути/вимкнути компресор) |

## 2. Датчики та їхні типи

> 📌 **Датчик** — це пристрій, який виявляє фізичний сигнал (рух, світло, тиск, температуру тощо) та генерує вихідний сигнал для комп’ютерної системи.

| Тип датчика | Що вимірює / виявляє | Приклади застосування |
| :--- | :--- | :--- |
| **Датчики температури** | Температуру навколишнього середовища | Системи опалення та охолодження, холодильники, печі, медичні термометри |
| **Датчики освітленості** | Видиме світло або невидиме випромінювання (рентгенівське, ІЧ, УФ) | Автояскравість екранів смартфонів і смарттелевізорів, вуличні ліхтарі |
| **Датчики тиску** | Тиск рідин або газів (діє як перетворювач) | Метеостанції, літаки, автомобілі |
| **Датчики наближення** | Присутність об’єктів без фізичного контакту (електромагнітні поля, світло, звук) | Парктронік в авто, роботизовані машини, вимкнення екрана телефона біля вуха |
| **Датчики диму** | Дим як індикатор пожежі | Системи пожежної сигналізації (кухні, спальні) |
| **Сенсорні датчики (дотику)** | Дотик, силу або тиск (замикання/розмикання ланцюга) | Смартфони, планшети, ноутбуки, пульти керування |
| **Датчики руху** | Присутність рухомого об’єкта (ІЧ-тепло, мікрохвилі, ультразвук, вібрації) | Охоронна сигналізація, автоматичні двері, вуличні ліхтарі, VR-гарнітури та контролери (*Kinect*) |

## 3. Робототехніка та дрони

Сучасні **автономні роботи** поєднують потужні процесори, удосконалені датчики, приводи, розпізнавання зображень і алгоритми ШІ. Вони виконують повторювані, складні або небезпечні завдання (наприклад, робота в екстремальних умовах або розмінування).

**Проблеми розвитку робототехніки:**
- **Соціальні:** чи зможуть роботи замінити людей і які професії під загрозою.
- **Фінансові:** чи справді роботизація знижує витрати, чи просто замінює людей дешевшою робочою силою.
- **Якісні:** чи можуть роботи виконувати роботу так само точно й ефективно, як людина.

> 📌 **Дрон** (англ. *Dynamic Remotely Operated Navigation Equipment*), або **БпЛА** (безпілотний літальний апарат) — літальний апарат (існують також наземні, водні та підводні дрони), яким керують дистанційно або автономно за планом польоту.

### Сфери застосування дронів
- **Цивільна:** реагування на надзвичайні ситуації, рятувальні операції, охорона правопорядку.
- **Соціальна:** фото- й відеозйомка з високою роздільною здатністю, журналістика.
- **Наукова:** дослідження, моніторинг забруднення, геодезія, археологія.
- **Комерційна:** транспортування і доставка товарів (розвантаження доріг).
- **Військова:** виконання завдань у ситуаціях, надто ризикованих чи неможливих для людини.

## 4. Автономне водіння та автоматичне гальмування

За класифікацією **Товариства автомобільних інженерів (SAE)** існує **6 рівнів автоматизації водіння**:

| Рівень | Назва | Хто керує і що автоматизовано |
| :---: | :--- | :--- |
| **Рівень 0** | Без автоматизації водіння | Водій вручну керує та контролює всі оперативні завдання |
| **Рівень 1** | Допомога водієві | Єдина автоматизована система (парктронік або утримання смуги); водій стежить |
| **Рівень 2** | Часткова автоматизація водіння | Вдосконалена система **ADAS** керує кермом і швидкістю; водій має бути готовий втрутитися |
| **Рівень 3** | Умовна автоматизація водіння | Авто виявляє оточення й приймає рішення; водій має бути напоготові перебрати керування |
| **Рівень 4** | Висока автоматизація водіння | Авто працює автономно, взаємодія не потрібна, але є функція ручного керування |
| **Рівень 5** | Повна автоматизація водіння | Повністю автономна робота в будь-яких умовах, увага людини не потрібна взагалі |

**Виклики автономного водіння:**
1. *Технічні виклики* (точні датчики та обчислювальні системи).
2. *Безпека і надійність* (відмовостійкість і прозорість прийняття рішень).
3. *Регулювання* (брак чітких правил і стандартів).
4. *Схвалення громадськістю* (формування довіри до автопілота).

**Автоматична гальмівна система** покладається на дані лазерів, радарів, ультразвуку, ІЧ-випромінювання, камер і **GPS** (для фіксованих небезпек, як-от знаки зупинки), щоб знизити швидкість, попередити водія або автоматично активувати гальма.
