## 1. Поняття масиву, сортування та бібліотеки NumPy

> 📌 **Масив даних** — структура даних, яка зберігає колекцію елементів одного типу в суміжних комірках пам’яті, що забезпечує миттєвий доступ за індексом.

> 📌 **Впорядкування (сортування)** — процес розташування елементів у певному порядку за заданою ознакою (за алфавітом, зростанням/спаданням чисел, датою).

У Python для великих числових масивів замість звичайних списків використовують бібліотеку **NumPy** (*Numerical Python*), оскільки масиви NumPy займають менше пам’яті й працюють значно швидше.

### 📖 Історична довідка
Бібліотеку **NumPy** створив у **2005 році** Тревіс Оліфант, об’єднавши попередні бібліотеки *Numeric* (Джим Гаґунін, 1995) та *Numarray*. Сьогодні це фундаментальний стандарт для наукових обчислень, аналізу даних, статистики, обробки зображень і машинного навчання в Python.

### Вбудоване сортування в Python
```python
marks = [12, 7, 9, 10, 8]
print(sorted(marks))               # [7, 8, 9, 10, 12]
print(sorted(marks, reverse=True)) # [12, 10, 9, 8, 7]
```
> 💡 Функції `sorted()` та метод `list.sort()` у Python використовують гібридний алгоритм **TimSort** (розроблений Тімом Пітерсом), що поєднує *Merge Sort* та *Insertion Sort*.

## 2. Класичні алгоритми сортування

| Алгоритм | Основна ідея | Особливості |
| :--- | :--- | :--- |
| **Сортування бульбашкою (Bubble Sort)** | Багаторазове порівняння сусідніх елементів та їхній обмін; більші «спливають» догори | Наочний, але повільний на великих даних (час зростає пропорційно квадрату кількості елементів) |
| **Сортування вибором (Selection Sort)** | Поділ на впорядковану й невпорядковану частини; пошук мінімального серед невпорядкованих і перенесення в кінець впорядкованої | Трохи швидший за бульбашкове |
| **Сортування злиттям (Merge Sort)** | Принцип «розділяй і володарюй»: рекурсивне розбиття на окремі елементи та попарне злиття у відсортовані підмасиви | Винайдений **Джоном фон Нейманом** у **1945 році**; ефективний |
| **Сортування вставками (Insertion Sort)** | Як розкладання карт у руці: черговий елемент вставляється на правильне місце серед уже впорядкованих | Зручний і швидкий для невеликих масивів |
| **Швидке сортування (Quick Sort)** | Вибір опорного елемента, розбиття (менші ліворуч, більші праворуч) і рекурсивне повторення для частин | Один із найшвидших на практиці |

### Одномірний масив: `np.sort()` vs `ndarray.sort()`
```python
import numpy as np

arr = np.random.randint(1, 100, size=10)
print("Початковий масив:", arr)
print("За зростанням:", np.sort(arr))          # повертає новий масив
print("За спаданням:", np.sort(arr)[::-1])

arr.sort()                                      # змінює масив «на місці»
print("Масив після сортування:", arr)
```

### Двовимірний масив і параметр `axis`
- `axis=0` — сортування **за стовпцями** (зверху вниз).
- `axis=1` — сортування **за рядками** (зліва направо).

```python
import numpy as np

arr = np.random.randint(10, 100, size=(4, 4))
print("Початковий масив:\n", arr)
print("Відсортований за стовпцями:\n", np.sort(arr, axis=0))
print("Відсортований за рядками:\n", np.sort(arr, axis=1))
```
