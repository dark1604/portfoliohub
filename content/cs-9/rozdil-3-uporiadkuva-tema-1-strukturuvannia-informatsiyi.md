# Тема 1. Структурування інформації (с. 58–64)

## 1. Структурована інформація та база даних

**Структурований** означає організований за певною системою. Структурована інформація подається у вигляді **таблиці**, що складається з:
- **рядків (записів)** — окремий об’єкт або подія;
- **стовпців (полів)** — конкретна характеристика із заголовком.

### Створення бази даних у Microsoft Access
1. Відкрийте **Microsoft Access** і виберіть **Пуста база даних**.
2. Введіть **Ім’я файлу** (наприклад, `My_class.accdb`) та за потреби змініть шлях через **Огляд**.
3. Натисніть **Створити**.

У режимі **Конструктор** (*Поля таблиці → Подання → Конструктор*) ви самостійно задаєте структуру таблиці: імена полів, типи даних та необов’язкові описи.

---

## 2. Типи даних і властивості полів

| Тип даних | Призначення |
| :--- | :--- |
| **Короткий текст** | Текст до **255** символів |
| **Довгий текст** | Блок тексту понад 255 символів (може містити форматування) |
| **Число** / **Велике число** | Числові дані для розрахунків (*Велике число*: від $-2^{63}$ до $2^{63}-1$) |
| **Дата й час** / **(розширені)** | Дати та час (розширені: роки від 0001 до 9999) |
| **Грошова одиниця** | Грошові значення (десяткові дроби, 4 знаки після коми) |
| **Автонумерація** | Унікальне число, яке Access автоматично створює для кожного запису (часто **первинний ключ**) |
| **Так / Ні** | Логічні (булеві) значення: `Yes/No`, `True/False`, `On/Off`, `1/0` |
| **Об’єкт OLE** | Прикріплення об’єктів Windows (зображення, книга Excel тощо) |
| **Гіперпосилання** | Адреса файлу чи вебсайту |
| **Вкладення** | Прикріплення файлів, фотографій (наприклад, фото учня) |
| **Обчислювальний** | Вираз на основі даних інших полів |

### Основні властивості полів
- **Розмір поля** — максимальна кількість символів або формат числа.
- **Маска вводу** — шаблон введення (наприклад, лише цифри або формат дати).
- **Підпис** — заголовок поля у формах, звітах і запитах.
- **Значення стандартне** — підставляється автоматично при створенні запису.
- **Правило перевірки** і **Текст перевірки** — умова коректності даних та повідомлення про помилку.
- **Обов’язково** — забороняє залишати поле порожнім.
- **Індексовано** — прискорює пошук і сортування за полем.

> 📌 **Ключове поле (Первинний ключ)** — це поле з унікальним значенням (позначене маленьким ключем), яке однозначно ідентифікує кожен запис у таблиці.

## 3. Зв’язки між таблицями

Щоб не дублювати дані, одну велику таблицю розбивають на кілька пов’язаних таблиць (приклад із підручника):
- **Учні:** `ID_учня` *(ключ)*, `Прізвище_та_ім'я`, `Дата_народження`, `Адреса`, `Місто`, `Поштовий_індекс`, `Номер_телефону`, `Клас`.
- **Предмети:** `ID_предмета` *(ключ)*, `Предмет`, `Клас`, `Учитель`.
- **Оцінки:** `ID_учня`, `ID_предмета`, `Оцінка_I_семестр`, `Оцінка_II_семестр`, `Річна_оцінка`.

### Як створити зв’язки
1. Відкрийте **Знаряддя бази даних → Зв’язки** і додайте всі таблиці.
2. Перетягніть `ID_учня` з таблиці *Учні* на `ID_учня` в таблиці *Оцінки* (тип зв’язку: **Один-до-багатьох**).
3. Аналогічно зв’яжіть `ID_предмета` з *Предмети* з полем у *Оцінки*.

> 💡 Поля для зв’язування мають бути **сумісних типів** (найчастіше `Автонумерація` + `Число`).

- **Забезпечення цілісності даних** — не дозволяє створювати записи, що посилаються на неіснуючі об’єкти.
- **Каскадне оновлення** — оновлює пов’язані записи при зміні ключа.
- **Каскадне видалення** — видаляє пов’язані записи при видаленні основного запису.
