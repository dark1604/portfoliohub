# Тема 3. Опрацювання текстових даних (с. 101–104)

## 1. Рядки (`str`) та нумерація символів

Текстові дані в Python мають тип **`str`** (*string* — рядок). Кожен символ має свій індекс:

| Пряма нумерація | `0` | `1` | `2` | `3` | `4` | `5` |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **Символ** | `P` | `y` | `t` | `h` | `o` | `n` |
| **Зворотна нумерація** | `-6` | `-5` | `-4` | `-3` | `-2` | `-1` |

## 2. Вбудована функція `len()` і методи роботи з рядками

> ⚠️ Важливо пам’ятати, що `len()` — це **функція** (викликається без крапки), а не метод рядка.

| Інструмент | Призначення | Приклад і результат |
| :--- | :--- | :--- |
| `len(text)` | Повертає довжину рядка (рахує літери, пробіли, розділові знаки) | `len("Привіт, світ!")` → `13` |
| `text.upper()` | Усі літери у верхній регістр | `"Python".upper()` → `"PYTHON"` |
| `text.lower()` | Усі літери у нижній регістр | `"ПрИвІт".lower()` → `"привіт"` |
| `text.capitalize()` | Перша літера велика, решта — маленькі | `"пРиВіТ СвІт".capitalize()` → `"Привіт світ"` |
| `text.replace(a, b)` | Замінює всі входження `a` на `b` (чутливий до регістру; 3-й аргумент `1` замінює лише перше) | `"Я люблю Python.".replace("Python", "Пайтон")` → `"Я люблю Пайтон."` |
| `text.split()` | Розбиває рядок на список слів (стандартно — за пробілами; або за вказаним розділювачем, напр. `","` для CSV) | `"Привіт як справи".split()` → `['Привіт', 'як', 'справи']` |
| `text.strip()` | Видаляє пробіли (або вказані символи) на початку й у кінці рядка (також є `lstrip()`, `rstrip()`) | `"ааааабанани.....".strip(".а")` → `"банани"` |
| `text.isalpha()` | Повертає `True`, якщо рядок не порожній і містить лише літери (працює і з кирилицею, і з латиницею) | `"Привіт".isalpha()` → `True`; `"Python3".isalpha()` → `False` |
| `text.find(sub)` | Повертає індекс першого входження `sub` або `-1`, якщо не знайдено (можна задати `start, end`) | `"Мені подобається Python".find("Java")` → `-1` |

> 📌 **Парсинг (Parsing)** — це процес аналізу рядка символів (тексту, коду, даних) для визначення його структури та перетворення у зручний структурований формат (наприклад, розбиття рядка методом `split()`).

> 💡 Усі методи рядків у Python **не змінюють** оригінальний рядок, а повертають новий рядок!
