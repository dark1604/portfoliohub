# Тема 5. Імпорт та експорт даних (с. 80–85)

## 1. Експорт даних із Microsoft Access

**Імпорт і експорт** дають змогу переносити дані між різними програмами (наприклад, в електронні таблиці для аналізу). Експортувати можна дані з будь-якої таблиці, запиту, форми чи звіту.

### Експорт до Microsoft Excel (`.xlsx`)
1. В *Області переходів* виділіть об’єкт (наприклад, таблицю `Учні`).
2. На вкладці **Зовнішні дані → Експорт** натисніть **Excel**.
3. Вкажіть шлях та ім’я файлу (наприклад, `Учні.xlsx`), за потреби оберіть опцію збереження форматування та натисніть **ОК → Закрити**.

### Експорт до текстового файлу (CSV)
1. Виділіть таблицю та натисніть **Зовнішні дані → Експорт → Текстовий файл**.
2. Введіть ім’я файлу (наприклад, `Учні.txt`) і натисніть **ОК**.
3. У Майстрі експорту оберіть **З розділенням** (*кома*, *крапка з комою*, *табуляція* тощо), поставте прапорець **Включити імена полів до першого рядка**, натисніть **Далі → Готово → Закрити**.

## 2. Імпорт даних до Microsoft Access

### Імпорт із файлу Microsoft Excel
1. Відкрийте базу даних і перейдіть на вкладку **Зовнішні дані → Імпорт і зв’язування → Нове джерело даних → З файлу → Excel**.
2. Оберіть файл (наприклад, `Учні.xlsx`) та спосіб:
   - *імпортувати дані до нової таблиці*;
   - *підключитися до джерела* (зміни в Excel автоматично відображатимуться в Access, але не навпаки).
3. У Майстрі імпорту відмітьте **Перший рядок містить заголовки стовпців**, перевірте типи даних для кожного поля, оберіть **Вибрати власний первинний ключ** (або дозвольте Access додати його), введіть назву таблиці й натисніть **Готово → Закрити**.

### Імпорт об’єктів з іншої бази Access (`.accdb`)
*Зовнішні дані → Нове джерело даних → Із бази даних → Access* → оберіть файл бази даних (наприклад, `My_class.accdb`) → у вікні *Імпортувати об’єкти* виділіть потрібні таблиці, запити, форми чи звіти → **ОК → Закрити**.

## 3. Аналоги та альтернативи Microsoft Access

| Інструмент | Особливості |
| :--- | :--- |
| **LibreOffice Base** | Безкоштовний десктопний компонент із відкритим кодом, найближчий замінник Access |
| **Google AppSheet** | Low-code / no-code платформа від Google; використовує Google Таблиці та хмарні бази для створення мобільних і вебдодатків |
| **Microsoft Power Apps** | Low-code / no-code платформа від Microsoft, інтегрована з Office 365 та SharePoint |
| **Airtable** | Хмарна платформа, що поєднує простоту електронної таблиці з реляційною базою даних |
| **PostgreSQL** | Потужна відкрита об’єктно-реляційна СКБД для великих систем (потребує окремих інструментів для інтерфейсу) |
| **Zoho Creator** | Хмарне середовище для створення бізнес-застосунків із мінімальним кодуванням |

> 📌 **No-code (або zero-code)** — технологія створення сайтів, чат-ботів, застосунків та ігор без необхідності писати код.
